# hxwl-01 听力验配记录

门店听力师的验配档案与听力曲线工作台 —— 听力曲线核验闭环原型。

## 技术栈

React + Vite + TypeScript + CSS，数据经 localStorage 本地落盘。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 核验闭环

- **数据录入**：每耳 0.5 / 1 / 2 / 4 kHz 的气导（AC）、骨导（BC）与掩蔽方式（未记录 / 气导掩蔽 / 骨导掩蔽 / 气导+骨导掩蔽）。
- **采用门槛（阻断项，逐条列出耳别与频率）**：
  - 骨导高于气导（BC dB > AC dB）→ 不能采用；
  - 气骨导差 ≥ 15 dB 且掩蔽方式为「未记录」→ 不能采用；
  - 双耳同频气导差 ≥ 15 dB → 较差耳进入待复核，复核完成前不能采用。
- **复核**：按耳记录复核结论（必填）与时间；复核后任何气导数据变更会使复核自动失效，需重新复核。
- **采用与冻结**：通过全部核验后「采用并冻结为 vN」，曲线变为只读。
- **复调**：只能从冻结版本发起，生成新草稿，采用时必须填写复调原因，形成 v1 → v2 → … 的版本链，可查看任意历史版本快照。
- **落盘一致性**：草稿、复核状态、冻结曲线与版本链全部写入 localStorage，刷新后状态完全一致。
