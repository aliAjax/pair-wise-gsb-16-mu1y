# hxwl-01 听力验配记录

门店听力师的验配档案与听力曲线工作台：可落盘的听力曲线核验闭环。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5101

## 功能：听力曲线核验闭环

- **双耳录入**：每耳 0.5 / 1 / 2 / 4 kHz 的气导、骨导阈值与掩蔽方式（未记录 / 无需掩蔽 / 气导掩蔽 / 骨导掩蔽），附双耳听力图（SVG）。
- **采用前核验**（违规即不能采用，并列出耳别与频率）：
  1. 骨导高于气导；
  2. 气骨导差 ≥ 15 dB 却未记录掩蔽方式；
  3. 气导或骨导阈值缺失（数据不完整）。
- **复核流程**：双耳同频气导差 ≥ 15 dB 时，较差耳进入待复核；复核完成前不能采用。复核完成后若改动该频率数值，复核自动失效需重新复核。
- **采用即冻结**：采用后曲线只读；复调只能基于冻结版本新建草稿，且必须填写复调原因，采用后形成 v1 → v2 → … 的版本链。
- **本地落盘**：全部状态（草稿、复核状态、版本链）保存在 localStorage，刷新后自动恢复、保持一致。

## 目录结构

- `src/lib/audiology.ts` — 领域模型与核验规则（纯函数）
- `src/lib/storage.ts` — localStorage 持久化
- `src/components/Audiogram.tsx` — 双耳听力图
- `src/components/EarTable.tsx` — 单耳录入 / 只读表
- `src/App.tsx` — 状态机与页面组装
